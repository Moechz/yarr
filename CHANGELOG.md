# Changelog

All notable user-visible changes to the Yarr TOS application package.

## 2.9-1 — 2026-11-15

### Added
- First release. Yarr (`nkanaev/yarr:v2.9`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8161 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/yarrdocker/`.
